# share-desk-gpt

Кроссплатформенная основа установщика и CLI для **share-desk-gpt**.

> **Текущий статус:** публичный репозиторий пока не содержит полноценной точки входа приложения. Поэтому эта версия создает только надежный слой установки и runtime и не придумывает отсутствующую функциональность.

## Что делает установщик

Он определяет `PATH`, проверяет Node.js/npm/npx, устанавливает Node.js только при необходимости, проверяет SHA-256 и создает команду `share-desk-gpt` в пользовательском PATH.

`npx` отдельно не устанавливается: он входит в npm через `npx`/`npm exec`.

В NixOS используется Nix вместо записи в `/usr/bin`. В SteamOS используется установка для пользователя, чтобы не изменять неизменяемую системную основу.

## Установка

Linux:

```bash
bash scripts/install.sh
```

Системная установка:

```bash
sudo bash scripts/install.sh --system
```

Windows:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\install.ps1
```

Проверка:

```text
share-desk-gpt --doctor
share-desk-gpt --version
```

## Платформы

Windows x64/ARM64 и Linux x64/ARM64/ARMv7. Для ARMv7 используется Node.js 22, поскольку Node.js 24 больше не выпускает актуальный Linux-бинарник ARMv7.

## Надежность

По умолчанию используется пользовательская установка: не нужны root/admin, существующий PATH не перезаписывается, удаление простое. NixOS и SteamOS обрабатываются отдельно из-за их собственной модели управления системой.

## Ограничение

CLI намеренно показывает только диагностику и фактический статус до тех пор, пока публичный репозиторий не получит настоящий entrypoint share-desk-gpt.
